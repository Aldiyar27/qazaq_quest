Что изменено:
- Квесты больше не берутся из кода во время работы сайта, а читаются из PostgreSQL.
- Добавлены таблицы: Quests, QuestPoints, QuestLocations, Rewards.
- Сохранены таблица Users и текущий дизайн пользовательской части.
- Добавлена админ-панель:
  - /Admin
  - создание квестов
  - редактирование квестов
  - удаление квестов
  - редактирование заданий
  - редактирование локаций
  - редактирование наград

Как зайти в админку:
- Зарегистрируй пользователя с email, в котором есть слово admin.
- Например: admin@qazaqquest.kz
- После входа в верхнем меню появится пункт Admin.

Важно:
- В form'е задания поле "Номер локации" связывает задание с локацией.
- При первом запуске сиды квестов переносятся в БД, если таблица Quests пустая.
- Для существующей БД добавлено создание недостающих таблиц через CREATE TABLE IF NOT EXISTS.
